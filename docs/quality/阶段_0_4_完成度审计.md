# 阶段 0～4 完成度审计

> 状态：工程闭环完成，产品质量门槛阻断
> 审计日期：2026-07-31
> 评估范围：`phase-0-4`

## 1. 判定原则

阶段状态按“实现、自动验证、产品证据”三层分别判定：

- 单元测试、集成测试和模拟器冒烟通过，只证明对应工程不变量。
- 公开语料和合成语料只用于回归与故障定位，不能替代正式产品会议语料。
- Hard Gate 只有在发布评估器读取来源可追溯、经过人工复核和去敏确认的
  `product-meeting` 完整矩阵，并输出全部门槛为 `passed` 后才算通过。
- `missing` 与 `failed` 都不能折算成 `passed`；未通过时不得激活候选 Profile、
  声称质量提升或合并 `dev`。

## 3. 机器可读缺项归因

当前
`docs/quality/evidence/android-emulator/phase-0-4-release-report.json`
判定为 `blocked`：22 项 `passed`、0 项 `failed`、26 项 `missing`。缺项不是
26 个互不相关的工程缺陷，而是同一正式证据链的四层输出：

| 证据层 | 缺失数 | 内容 |
|---|---:|---|
| 语料与人工复核证明 | 9 | corpus ID、证据类别、manifest 哈希、来源、许可、复核证明哈希、复核 UTC、样本数、去敏确认 |
| 同设备评测声明 | 2 | 同一语料、同一设备 |
| 原始证据绑定 | 2 | raw metrics 引用及 SHA-256 |
| 完整矩阵派生指标 | 13 | 双模型固定窗口、Profile/Pipeline 完整性、Preview P95、Base/Small VAD 召回、语音首尾、Base 事实召回、静音/噪声统计、Small RTF/延迟样本数 |

因此，不能通过手工填写发布输入中的布尔值关闭这些门槛。唯一有效路径是：

1. 人工试听私有复核包的 90 段候选，逐段确认分类、敏感信息、批准状态和语音事实。
2. 由晋升器生成至少 20 段静音、20 段纯噪声、20 段带事实语音的
   `product-meeting` manifest，并绑定复核证明。
3. 在同一 Android 设备完成 Base/Small × Baseline/Preview/Final ×
   fixed-window/生产 VAD/召回候选 VAD 的完整矩阵。
4. 由聚合器生成脱敏质量报告，再由输入构建器和发布评估器重新判定。

## 4. 当前人工复核入口

私有包位于：

```text
.spike/review/product-meeting-07-29-vad-informed-surplus/
```

其中：

- `review.csv` 包含 90 行候选；不预填任何人工批准或去敏结论。
- 20 段 speech 已附 Base ASR 草稿，其中 16 段草稿非空，只用于辅助定位和试听。
- `review-silence.wav`、`review-noise-only.wav`、`review-speech.wav` 可用于顺序试听。
- `review-attestation.template.private.json` 是待填写模板；正式证明不得由 VAD 或 ASR
  草稿自动批准。

人工复核完成后依次运行：

```powershell
python .spike/tools/complete_private_review_attestation.py `
  --template .spike/review/product-meeting-07-29-vad-informed-surplus/review-attestation.template.private.json `
  --review-csv .spike/review/product-meeting-07-29-vad-informed-surplus/review.csv `
  --corpus-id <正式语料 ID> `
  --reviewed-at-utc <UTC 时间> `
  --reviewed-by-role <不含姓名的复核角色> `
  --output <私有复核证明路径>

dart run tool/benchmarks/promote_reviewed_whisper_corpus.dart `
  --candidate-manifest .spike/corpora/product-meeting-07-29-vad-informed-surplus/manifest.private.json `
  --review-attestation <私有复核证明路径> `
  --environment .spike/corpora/product-meeting-07-29-vad-informed-surplus/environment.private.json `
  --repository-root . `
  --output <正式 product-meeting manifest 路径>
```

## 5. 合并判定

当前分支可作为阶段 0～4 的工程候选保留，但不能声明阶段 0～4 Hard Gate 全部完成，
也不能合并 `dev`。解除阻断必须以重新生成的机器可读报告为准；只有报告
`decision=go` 且 OCR 无未解决 Critical/High，才能进入后续交付判断。
