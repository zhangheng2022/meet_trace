# 在线接入与本地字幕优化：执行和验证

本次需求以 [Alpha PRD V1.9](../product/Alpha_PRD_无登录版.md) 为准。在线仅代表用户指定的转录服务，没有会迹后台、登录或云同步。

## 使用在线模型

1. 设置 → 转录来源 → 添加在线来源，填写名称、协议、完整 URL、任意模型 ID、API Key。API Key 自动组成 Bearer；非 Bearer 认证放在高级连接设置的认证头 JSON。
2. 选择 Audio Transcriptions 或 Chat Audio 时，只在会后上传，不提供实时字幕；需要会中字幕时选 Realtime Transcription。协议字段代表消息格式，不代表模型厂商；私有协议通过兼容网关适配，不能仅改一个 URL 就宣称所有服务都兼容。
3. 高级设置提供语言、术语提示、上传上限与请求超时。完整端点不得含密钥，私有网关明文地址只允许本机回环。普通远端要求 HTTPS/WSS。
4. 保存后测试协议连接：确认会发送生成的测试音频，可能计费；通过只证明连接与响应格式，不能证明真实会议的准确率。
5. 开始会议时选择来源。在线再次展示接收目标、实时能力与费用。录音开始之后才初始化在线推理；认证、超时、网络或积压故障只停止预览，PCM 持续落盘。
6. 结束后重新读取完整 PCM，以同一锁定来源生成最终稿。实时字幕可能另计一次识别费用。会后详情可换来源重转录，成功后才激活新快照；旧结果和事实音频在失败时保持不变。

详细协议、大小限制、时间精度和网关示例见 [在线协议说明](online_asr_protocols.md)。未报告的服务端模型版本显示未知；只有音频窗口时明确提示范围，不能冒充逐词时间戳。

配置保存时凭据写入系统安全存储，数据库只存引用。修改认证会生成新引用；历史会议继续使用旧引用。更改端点协议、域名或端口时必须重新填写认证或填入 `{}` 明确清空，不能将留空保留的旧凭据自动发到新接收方。删除配置入口保留旧会议重试所需凭据；Alpha 全清删除所有本应用凭据。iOS 使用首次解锁后本设备可访问的 Keychain，Android 禁止自动备份，Windows 使用插件提供的系统加密存储；平台要求参考 [flutter_secure_storage 官方说明](https://pub.dev/packages/flutter_secure_storage)。

## 优化本地模型

固定 SenseVoice、官方 sherpa_onnx、auto 语言与 ITN 均保留，优化发生在音频分段与实时预览调度。进行中语音约 2 秒后可提交临时预览；实际刷新间隔根据当前推理耗时放宽。稳定句替换同一段临时文字。队列拥堵只保留最新临时窗口，迟到结果不得覆盖新的段，空稳定结果撤回临时文字。

Silero 的 maxSpeechDuration 不是可靠硬边界，因此额外限制实际音频窗口。预览可以跳过，事实 PCM 不能跳过。暂停先交付已落盘尾部，等待有界且不等待模型推理。完成后仍从全量 PCM 单独生成最终稿。

## 在自己的设备上验收

1. 准备有授权、人工校对的会议样本，覆盖安静、噪声、远场、口音、术语、中英混合与连续长句。同一 PCM、同一设备、相同供电和线程条件分别运行旧版与新版；不要把合成协议测试当准确率证据。
2. 分开统计临时字幕与最终稿：中文 CER、英文 WER、术语召回、首字延迟 P50/P95、稳定字幕延迟、RTF、丢弃预览数和事实 PCM 完整性。
3. 用 `dart run tool/benchmarks/evaluate_asr.dart --help` 查看 JSONL 输入格式。输入真实 reference/hypothesis 和实际时间记录；工具不会生成虚构改善幅度。没有足够样本时，先记录基线，不调高模型负载。
4. 依次验证长时间连续说话、暂停紧接结束、后台录音、断网/错误凭据、上传超限、在线换本地重转录、处理中编辑配置，以及失败后原 PCM 摘要和旧快照保持不变。
5. 在低端 Android、iPhone 和 Windows 实机分别记录结果。测试和模拟协议通过不等于实际云服务联调或真机性能通过。

```powershell
dart format lib test tool/benchmarks
flutter analyze
flutter test
flutter build apk --debug
flutter build windows --debug
```

iOS 构建与 Keychain 联调需 macOS/Xcode 和相应签名能力。本次数据代提升至 4、数据库 schema 至 8，沿用用户确认的 Alpha 全清策略；仅在安装前明确确认后进入破坏性升级，录音或最终处理中不安装。不在开发验收时启动用户真实数据目录的破坏性升级。
