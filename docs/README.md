## 当前实现状态

- 默认且唯一可选 ASR 为 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`。
- 其他模型待定；设置页保留真实模型选择器，但不显示占位模型、等级或“即将推出”。
- SenseVoice 和 Silero VAD 权重不进入安装包，首次初始化时下载；未就绪前不进入首页。
- 固定下载量为 `239,762,595` 字节，小于十进制 `300,000,000` 字节上限。
- Wi-Fi 自动下载；移动网络必须先展示体积与数据费用提示，并取得绑定当前资源版本集合的持久同意。
- 下载支持 HTTPS Range 续传。用户暂停后保留分片；下次继续时不重复已完成字节。
- 第二次启动仅做安装记录、固定文件集合和字节数的本地快速检查，不联网检查版本。缺失、损坏或 Engine 初始化失败进入修复流程。
- 会议创建时锁定模型 ID、版本、`language=auto` 和 `useInverseTextNormalization=true`，会中与最终转录共用，不自动切换或混合输出。
- Alpha 数据库采用干净安装策略。检测到旧 schema 时阻断升级并要求先导出录音；不会静默删除录音。

## 维护规则

- 改变 P0 或验收标准前先更新 PRD，并执行 `$grill-me`。
- 改变模型、Manifest、下载、锁定或降级策略时同步更新技术方案和质量证据。
- 下载模型、真实录音、评测语料、密钥、`build/` 和 `coverage/` 不得提交。
- 活动文档不保留旧方案并列副本；历史由 Git 保存。
