# 会迹（MeetTrace）Android + iOS Alpha 产品需求文档（无登录版）

> 版本：V0.7
> 日期：2026-08-01
> 状态：SenseVoice 初始化下载基线
> 技术方案：[端侧 SenseVoice 转录技术方案](./端侧SenseVoice转录技术方案.md)

## 1. 产品目标与边界

会迹是一款 Android + iOS 自适应的本地会议记录 Alpha。用户无需登录即可录音、查看会中临时转录，并在会议结束后基于完整事实音频生成最终转录和带原文证据的总结。

产品边界：

- 本地音频是唯一事实源；ASR 变慢、积压、损坏或失败时录音必须继续。
- 不提供登录、跨设备同步或云端实时 ASR。
- 云端 AI 总结只允许上传最终文本，不上传音频；关键结论保留带时间戳的原文证据。
- 当前 ASR 只支持 SenseVoice；其他模型待定，不承诺等级、发布时间或自动切换。
- Android 与 iOS 分别达到门槛后才允许发布，Android 证据不能替代 iOS 证据。

## 3. P0 范围

- 无登录本地工作区和自适应手机/平板 UI。
- 可靠事实录音、检查点、封存和崩溃恢复。
- SenseVoice 与 Silero VAD 首次初始化下载、续传、校验和修复。
- 会中临时转录、有界积压和仅录音降级。
- 完整事实音频的最终转录、快照原子激活和重试。
- 可降级的说话人分离、手工标签、AI 总结和证据映射。
- 分享不包含音频；删除会议清理该会议的本地派生数据。
- Android/iOS 后台录音、系统中断、可访问性和安装包审计。

不在 Alpha 范围：登录、同步、云端实时 ASR、会议中切换模型、混合模型输出、自动替用户切换模型、下载远端“最新版本”。

## 4. 首次初始化流程

1. App 完成本地数据库和服务初始化。
2. 读取固定 SenseVoice 与 Silero VAD Manifest。
3. 若本地安装记录、活动版本、固定文件集合和字节数均匹配，直接进入首页；该快速路径不得联网。
4. 未就绪时检查资源总下载量不超过十进制 `300,000,000` 字节，并检查应用所在卷至少有 `805,306,368` 字节可用空间。
5. 无网络时停留在初始化页，显示离线原因和重试入口。
6. Wi-Fi/非计费网络自动开始下载。
7. 移动或未知网络先展示固定总量约 `239.8 MB`、可能产生数据费用和暂停后可续传；用户明确同意后下载。同意只对完全相同的模型/VAD ID、版本、哈希和大小集合生效，并持久化供续传使用。
8. 下载仅允许 HTTPS，使用 `.partial` 临时文件和 HTTP Range；暂停保留分片，校验失败不激活。
9. 两项资源均通过固定文件集、字节数和 SHA-256 校验后原子切换到活动目录，再进入首页。
10. 用户拒绝、暂停或下载失败时留在初始化页；不得以仅录音模式绕过首次阻断。

当精确可用空间不足时，界面显示差额字节数。第二次启动的快速检查发现缺失/大小异常，或 Engine 初始化失败时，进入同一修复流程并执行完整校验。

## 5. 会议模型锁定

- 首页开始会议时直接读取全局默认 SenseVoice，不提供本场覆盖。
- 创建会议时原子保存请求模型、录音模型、版本、`language=auto` 和 `ITN=true`。
- 录音开始后配置不可修改；会中预览和最终转录使用同一配置。
- 推理失败时转为仅录音，保留诊断和可重试入口，不自动切换或混合旧结果。
- 最终转录只基于完整事实音频；新快照成功激活前保留旧活动快照。

## 6. 功能要求

### FR-001 可靠录音

- PCM 音频写入与 ASR/VAD 独立运行。
- 有界队列可以丢弃最旧的预览任务，但不得丢失录音字节。
- 30 分钟会议音频完整率必须为 100%，并可播放到末尾。

### FR-002 初始化资源管理

- Manifest 固定资源 URL、大小、SHA-256、模型版本、最低 App 版本和许可 NOTICE。
- ASR + VAD 固定下载总量必须不超过 `300,000,000` 字节。
- 下载前最少可用空间为 `805,306,368` 字节。
- 支持断点续传、暂停、继续、失败重试、严格校验和原子激活。
- 不提供删除当前唯一模型的入口；模型与会议历史相互独立。

### FR-003 转录

- 单次识别窗口最大 15 秒，长语音用重叠窗口确定性合并。
- 每个片段包含全局 `start_ms/end_ms`、模型 ID、版本和修订状态。
- 预览失败不影响事实音频；最终转录失败不覆盖旧快照。

### FR-004 数据与隐私

- 音频、ASR 和转录默认留在设备。
- 日志只记录白名单诊断字段，不记录音频或完整转录文本。
- 删除会议时级联删除该会议音频、转录、摘要和索引。
- 旧 Alpha schema 不自动迁移或删除；阻断并提示先导出录音后干净安装。

## 7. 性能与质量门槛

| 指标 | 门槛 |
| --- | --- |
| ASR + VAD 下载量 | ≤ `300,000,000` 字节（十进制） |
| 初始化空间预检 | ≥ `805,306,368` 可用字节 |
| RTF | P95 `< 0.5` |
| 结果延迟 | 语音段结束后 P95 `≤ 3 s` |
| 关键事实召回率 | `≥ 85%` |
| 30 分钟音频完整率 | `100%` |

30 分钟目标设备测试必须记录绝对电量变化、起止温度、最高温度、内存峰值和热降频现象，不以相对旧模型的百分比替代。指标须在 Android 与 iOS 目标设备、同一固定语料上分别留证。

## 8. 验收场景

| ID | 场景 | 预期 |
| --- | --- | --- |
| AT-01 | 干净安装，安装包审计 | APK/IPA 不含 `.onnx`、模型 token 权重或旧模型 ID |
| AT-02 | 首次启动 Wi-Fi | 自动下载约 239.8 MB，校验后才进入首页 |
| AT-03 | 首次启动移动网络 | 未明确同意前不下载；同意绑定固定资源版本集合 |
| AT-04 | 暂停与重启 | 保留 `.partial`，继续时通过 Range 复用已下载字节 |
| AT-05 | 无网络/空间不足 | 留在初始化页；显示可操作错误与精确空间差额 |
| AT-06 | 第二次离线启动 | 仅本地快速检查成功，直接进入首页，不远端查版本 |
| AT-07 | 缺失、损坏或 Engine 失败 | 进入修复流程，完整校验后恢复；不静默切换模型 |
| AT-08 | 设置页 | 仅一项 SenseVoice；无删除、等级、占位或待定入口 |
| AT-09 | 开始会议 | 锁定 ID、版本、auto 和 ITN，预览/最终共用 |
| AT-10 | ASR 积压或失败 | 允许丢预览任务，录音完整且继续 |
| AT-11 | 最终转录失败 | 保留音频和旧快照，错误可诊断、可重试 |
| AT-12 | 30 分钟会议 | 音频 100% 完整，达到 RTF/延迟/召回并记录能耗温控 |
| AT-13 | 旧 Alpha 数据库 | 阻断启动，提示先导出；数据库和录音未被删除 |
| AT-14 | Android/iOS 系统中断 | 准确呈现平台状态，可恢复已落盘事实音频 |
| AT-15 | 手机/平板与无障碍 | 关键页面无溢出，返回手势、Dynamic Type/VoiceOver 可用 |

## 9. Alpha 完成定义

- 自动化覆盖 Manifest、下载上限、空间预检、移动网络同意、续传、校验、快速启动、锁定配置和旧库阻断。
- `flutter analyze`、`flutter test`、Android Debug 构建和 APK 权重审计通过。
- Android 与 iOS 目标真机完成 AT-01～AT-15 的适用项；缺少任一平台证据时发布状态保持 `blocked`。
- 未解决的 OCR Critical/High 缺陷为零。

## 10. 变更规则

新增第二模型、改变首次阻断、下载上限、空间门槛、网络同意、会议锁定或发布门槛，均属于产品范围变化：必须先更新本 PRD 并运行 `$grill-me`，再修改代码和技术方案。
