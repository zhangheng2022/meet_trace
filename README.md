# 会迹（MeetTrace）

本地优先的 Android + iOS 会议录音、端侧转录与说话人分离应用。

- 本地事实音频优先，实时转录变慢或失败时录音继续。
- 首次初始化按固定 Manifest 下载并校验 SenseVoice、Silero VAD、Pyannote 与 3D-Speaker；完整资源集合未就绪前不进入首页。
- 会议结束后并行生成最终转录与普通话说话人分离结果，失败时可降级为单一说话人。
- 文本与音频分别分享；音频分享需二次确认，源录音始终保持不变。
- Android + iOS Alpha 不提供登录或跨设备同步，并分别遵循两端原生交互与后台生命周期。

项目资料从[活动文档索引](docs/README.md)进入；[产品上下文](PRODUCT.md)与[交互视觉规范](DESIGN.md)分别服务于产品、设计和实现协作，冲突时以活动 PRD 为准。
