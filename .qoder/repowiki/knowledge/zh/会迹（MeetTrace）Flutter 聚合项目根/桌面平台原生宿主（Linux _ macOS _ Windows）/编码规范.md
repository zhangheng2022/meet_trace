- 每个平台的入口函数都仅负责初始化 Flutter 项目（DartProject/Dart entrypoint arguments）、创建窗口对象并进入平台事件循环，业务逻辑全部委托给 Flutter 层。
- 插件集成通过 `flutter/generated_plugin_registrant.*` 自动注册，平台侧不直接 include 具体插件头文件，而是依赖 CMake/Xcode 生成的链接规则。
- 构建配置按 Debug/Profile/Release 三模式分离，Linux/Windows 通过 CMake 的 `APPLY_STANDARD_SETTINGS` 函数统一设置编译标准与警告选项，macOS 通过独立 xcconfig 文件管理。
- 安装阶段统一将 `flutter_assets`、Flutter 动态库、AOT 库及 native_assets 复制到 bundle 目录，确保可执行文件与资源相对路径一致。
