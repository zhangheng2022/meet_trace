本模块由两个独立的工具脚本组成，无共享代码：
- `evaluate_alpha_release.dart` 是 Dart CLI 入口，通过 `dart:io` 读取 JSON 输入文件，调用领域层 `package:meettrace/domain/use_cases/evaluate_alpha_release.dart` 中的 `EvaluateAlphaReleaseUseCase` 执行评测逻辑，并将结果以缩进 JSON 输出到 stdout 或指定文件；退出码按 `AlphaReleaseDecision` 映射为 0/go、1/noGo、2/blocked。
- `inspect_debug_apk.ps1` 是 PowerShell 脚本，使用 `tar -tf` 枚举 APK（ZIP）内部条目，基于正则匹配检测禁止的模型权重（`.onnx`、`.tflite`、`model.int8` 等）、用户音频数据以及原生 `.so` 库的 ABI，验证必需 assets（manifest.json、NOTICES.Z 等）是否齐全，最终将报告写入 `.spike\results\apk-inspection.json`。
- `alpha_release_input.example.json` 提供评测输入的 JSON Schema 示例，定义 `schemaVersion`、`corpus`、`environment`、`senseVoice`、`acceptanceEvidence`、`release` 等字段结构。
依赖方向单向：Dart 脚本依赖 meettrace 领域层的 Use Case，PowerShell 脚本仅依赖系统 `tar` 命令，两者互不依赖。
