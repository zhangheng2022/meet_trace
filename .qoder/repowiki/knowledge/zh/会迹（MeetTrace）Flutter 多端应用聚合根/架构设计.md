根目录作为 Flutter 包的聚合根，通过 pubspec.yaml 集中声明依赖、assets 与 flutter 配置，协调以下子模块：shared_dart_code 提供 domain/data/ui 分层业务逻辑；android_platform、ios_platform、desktop_platforms 分别作为各平台宿主承载 Flutter 引擎并桥接系统能力；assets_and_models 集中管理模型清单与许可证文件并通过 assets 段被 Flutter 打包；documentation 维护 PRD/架构/质量证据链；tooling_benchmarks 与 development_tools 提供 Alpha 评测与 Graphify 图谱。各平台宿主通过 flutter: dependencies 指向 shared_dart_code，形成「单包多宿主」结构，确保所有平台共享同一份业务实现。skills-lock.json 锁定外部 Agent Skills 来源以保证构建可重现性。
