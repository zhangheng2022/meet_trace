该模块为纯静态资源目录，无可执行代码，由上层应用读取以完成模型发现、下载与校验。
- `models/manifest.json`：统一模型清单，采用 schemaVersion=1 的 JSON 结构，每个 modelId 描述一个 ONNX 模型及其所需文件的 path、bytes、sha256 校验和与下载地址，并通过 license.noticePath 指向对应的 NOTICE 文件。
- `models/silero-vad-manifest.json`：独立 VAD 模型清单，除 files 外还包含 sampleRate、windowSize 等运行时参数以及 source.documentationUrl/downloadUrl/releaseAssetId 等上游来源信息。
- `licenses/`：存放各模型上游的 LICENSE.txt 与 NOTICE.txt，路径与 manifest 中的 noticePath/licensePath 一一对应，形成“清单→许可证”的双向引用关系。
依赖方向单向：上层代码 → 读取 manifest → 解析 files 列表 → 按 sha256 校验下载内容 → 展示 licenses 中的许可信息。
