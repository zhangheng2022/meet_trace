该模块是标准的 Flutter Android 宿主工程，采用 Gradle Kotlin DSL 构建：
- `settings.gradle.kts` 通过 `includeBuild` 引入 Flutter SDK 中的 `flutter_tools/gradle`，并声明 Android 9.0.1、Kotlin 2.3.20 插件版本。
- `build.gradle.kts` 将根 build 目录重定向到仓库根 `../build`，统一多子项目产物输出。
- `app/build.gradle.kts` 应用 `com.android.application` 与 `dev.flutter.flutter-gradle-plugin`，配置 compileSdk/targetSdk/minSdk=24、Java/Kotlin JVM_17，并通过 `flutter { source = "../.." }` 指向 Flutter 源码根目录。
- 入口 Activity `MainActivity.kt` 直接继承 `io.flutter.embedding.android.FlutterActivity`，无额外逻辑，由 Flutter Engine 接管 UI。
- `AndroidManifest.xml` 声明 INTERNET、RECORD_AUDIO、FOREGROUND_SERVICE_MICROPHONE、POST_NOTIFICATIONS、WAKE_LOCK 等权限，注册 `com.pravera.flutter_foreground_task.service.ForegroundService` 用于后台录音，并保留 Flutter Embedding v2 元数据。
- 资源位于 `app/src/main/res/`，包含启动页背景与各密度 launcher 图标。
- 依赖方向单向：Android 宿主仅承载 Flutter 引擎，业务逻辑全部在 Flutter 侧实现。
