本模块由三个并列的桌面平台子目录组成，每个目录都是一个独立的 Flutter 桌面宿主工程：
- `linux/`：使用 CMake 构建，入口为 `runner/main.cc`，通过 GObject/GLib 创建 `MyApplication` 并调用 `g_application_run`；依赖 GTK 3（`pkg_check_modules(GTK REQUIRED IMPORTED_TARGET gtk+-3.0)`），插件注册由 `flutter/generated_plugin_registrant.*` 自动生成。
- `macos/`：Xcode 工程（`.xcworkspace` + `.xcodeproj`），入口为 Swift 的 `AppDelegate.swift`（继承 `FlutterAppDelegate`），窗口由 `MainFlutterWindow.swift` 管理，构建配置通过 `Configs/*.xcconfig` 与 `Flutter-Debug.xcconfig`/`Flutter-Release.xcconfig` 分离。
- `windows/`：CMake + Visual Studio 工程，入口为 `main.cpp` 中的 `wWinMain`，通过 `flutter_window.cpp`/`win32_window.cpp` 封装 Win32 窗口消息循环，资源文件由 `Runner.rc` 和 `resources/app_icon.ico` 提供。
三个平台共享相同的二进制名 `meettrace`，并通过各自的 `CMakeLists.txt` 或 Xcode scheme 将 `flutter/` 子目录（包含 `generated_plugin_registrant` 和 `ephemeral` 生成物）纳入构建流程，安装阶段统一将 `data/flutter_assets`、`lib` 下的 Flutter 库及 AOT 产物打包到 bundle 中。
