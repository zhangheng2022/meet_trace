- CLI 脚本通过命令行参数接收输入/输出路径，并在参数非法时向 stderr 输出中文提示后设置非零 exitCode 退出。
- JSON 输入遵循带 `schemaVersion` 字段的版本化结构，各子对象（如 `corpus`、`environment`、`senseVoice`、`release`）使用 null 占位表示可选字段。
- PowerShell 脚本使用 `$ErrorActionPreference = 'Stop'` 配合显式 `throw` 进行错误处理，并通过 `[ordered]@{}` 构造有序报告字典。
- 文件 I/O 失败统一捕获为特定异常类型（`FormatException`、`FileSystemException`）并映射到不同 exitCode，便于 CI 区分错误原因。
