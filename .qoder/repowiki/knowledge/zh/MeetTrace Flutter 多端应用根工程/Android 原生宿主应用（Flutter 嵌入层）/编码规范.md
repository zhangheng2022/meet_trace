- Android 工程使用 Gradle Kotlin DSL（`.kts`）而非 Groovy，并在顶层 `build.gradle.kts` 中集中重定义 build 目录以统一产物位置。
- MainActivity 保持极简，直接继承 `FlutterActivity` 而不添加自定义逻辑，所有业务代码放在 Flutter 侧。
- 构建配置通过 `flutter.compileSdkVersion`、`flutter.ndkVersion` 等属性动态获取 Flutter 工具链版本，避免硬编码。
- 调试与发布构建共用同一签名配置（release 复用 debug signingConfig），便于快速验证 release 流程。
