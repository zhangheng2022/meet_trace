# Q: 可以测试真实录音场景吗

## Answer

Expanded from original query via vocab: [recording, audio, device, integration, test, background, failure, recovery]. Patrol可以在真机上处理麦克风权限、点击开始/停止、按Home进入后台、重新打开应用并观察UI，从而驱动真实RecordPcmAudioCapture录音。但Patrol不负责向麦克风注入确定性语音，也不能仅凭UI证明PCM完整、ASR准确或能耗温控达标。建议Patrol与现有reliable_recording_test组合：Patrol驱动用户和OS流程，测试Harness保留真实录音/前台生命周期/存储并暴露只在测试组合根存在的RecordingProbe，断言文件字节、完整率>=0.98、checkpoint finalized和丢预览数。受控内容需用外置扬声器播放固定脱敏PCM，或继续用live_preview_replay_test绕过麦克风做确定性ASR指标。来电、蓝牙、锁屏、强制进程终止等并非Patrol通用能力，需要ADB/Xcode/实验室设备编排或人工验收。
