# Q: Patrol 详细说明

## Answer

Expanded from original query via vocab: [integration, test, testing, flutter, android, ios, recording, device, audio, sharing]. Patrol是建立在flutter_test与integration_test之上的Flutter原生E2E框架：Dart测试使用Patrol finder操作Widget，通过PlatformAutomator连接Android instrumentation或iOS XCTest控制权限、Home、系统分享和原生UI；patrol_cli负责构建、安装、执行和原生报告。会迹Flutter 3.44.9、Android minSdk24、iOS13满足当前Patrol要求。推荐保留现有两条integration_test做PCM/模型/RTF指标，新增独立patrol_test目录做权限、前后台、恢复和分享主链。Android需PatrolJUnitRunner与AndroidX Test Orchestrator；iOS当前仓库使用Swift Package Manager且无Podfile，应采用Patrol 4.7+ SPM配置并新增RunnerUITests，真机还需单独签名。生产main通过SentryBootstrap.run调用runApp，Patrol测试必须抽取可复用的应用初始化/构造入口而不能直接运行生产main。首次初始化资源约286MB，不适合每条测试全清重下，应分Fake依赖UI测试与真实资产设备验收两组。Patrol MCP可让AI运行、截图和读取native tree，但断言仍应固化在Dart测试中。
