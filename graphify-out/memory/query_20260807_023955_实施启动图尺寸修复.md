# Q: 实施启动图尺寸修复

## Answer

统一 Android/iOS 原生启动标志的可见尺寸为约 64x54dp/pt；Android 12 使用 1152 透明画布但保持 256x212px 标志边界；Flutter 品牌动画从 64dp 接续到 52dp。已生成平台资源，新增像素级回归测试，并通过 flutter analyze、457 项 flutter test、Android debug APK 构建及 Android 16 冷启动实测。
