# Q: 查询当前启动异常

## Answer

Expanded from original query via graph vocab: [app, application, main, startup, launch, bootstrap, initialization, runtime, exception, windows, plugin, runner]. 当前 Windows 调试实例的 main isolate 暂停于 StateError：databaseFactory not initialized。精简堆栈为 sqflite_common databaseFactory getter -> MeetTraceDependencies.create（lib/app/meettrace_dependencies.dart:100）。项目直接读取 package:sqflite/sqflite.dart 的全局 databaseFactory，但 Windows 没有为它注册实现；sqflite_common_ffi 仅位于 dev_dependencies 且只在测试中调用 sqfliteFfiInit/databaseFactoryFfi。FutureBuilder 最终会把错误映射为通用“本地能力准备失败”，因此界面提示并非真实的磁盘空间问题。这是 Windows 启动兼容性问题，不是前一个 C4819 编译问题，也没有证据表明 Android/iOS 启动受影响。
