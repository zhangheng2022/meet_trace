# Q: 开始会议按下状态样式异常

## Answer

Expanded from original query via graph vocab: [start, meeting, press, control, footer, state, style]. meeting_list_view.dart 的首页开始会议底栏直接使用 FTappable 默认回弹，按下会将全宽区域缩放至 0.97 并暴露底层表面。修复为禁用几何回弹，通过 pressed variant 在 120ms 内把 primary 向 primaryForeground 混合 12%，保持全宽边缘稳定，释放后恢复；新增组件测试覆盖按下、释放和回调。
