# Q: 修复安卓标题栏为沉浸式

## Answer

Expanded from original query via graph vocab: [android, system, overlay, status, edge, safe, area, application, view]. Forui 的 FScaffold/FHeader 已通过 SafeArea 负责标题避让，并从 FColors.systemOverlayStyle 写入系统栏样式；灰色状态栏来自默认样式未指定透明 statusBarColor。修复应在主题令牌中统一使用透明状态栏并按背景亮度选择图标，同时在应用启动显式启用 SystemUiMode.edgeToEdge，Android LaunchTheme/NormalTheme 同步透明状态栏以避免启动闪灰。
