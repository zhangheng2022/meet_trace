# Q: 说话人 分离功能为什么没实现

## Answer

Expanded from original query via graph vocab: [speaker, diarization, diarizer, embedding, segmentation, sensevoice]. 结论：功能主体已经实现，但生产构建被安全门禁主动关闭。真实 SherpaOnnxSpeakerDiarizationService、独立 isolate worker、Pyannote 与 3D-Speaker 资源、最终 ASR 并行编排、说话人映射、UI 开关和单说话人降级均存在。当前 sherpa_onnx 1.13.4 的 Dart OfflineSpeakerDiarization.process* 未释放整段音频的原生 Float 输入缓冲区，30 分钟 16kHz 音频每次至少遗留 115,200,000 B；终止 isolate 不能释放这块原生堆。项目禁止私有 API、自建 FFI 或原生桥接规避，因此生产组合根固定装配 OfficialBindingBlockedSpeakerDiarizationService，能力被标记 unavailable，最终流程降级为 speaker-1，详情页开关禁用。重新启用需要官方包修复、升级依赖、切回真实服务，并完成 threshold 校准以及 Android/iOS 30 分钟重复任务的内存、DER、人数误差和 RTF 验收。
