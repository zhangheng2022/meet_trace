# Q: 结束保存一直显示正在保存

## Answer

根因是 ReliableRecordingService.stop 对平台 capture.stop 无界等待。现增加默认 5 秒有界等待；超时后取消音频订阅，等待已排队写盘完成，封存现有 PCM 并将平台资源释放转为不阻塞保存结果的后台清理。新增 stop 永不返回的回归测试。
