# Q: 根据当前项目，给我一份基于github的版本发布流程方案

## Answer

基于当前仓库，建议采用 PR 门禁、master 候选构建、Environment 审批、同一 SHA 双平台候选、人工真机验收、不可变 tag 与 GitHub prerelease 的流程。现状为 iOS unsigned 与 TestFlight 已成功运行，但无 tag/Release、master 无 ruleset、Android release 仍为 debug 签名、版本与 PRD 标识未治理、自动发布门禁仍只覆盖 AT-01 至 AT-15。公开源码仓库只发布门禁报告、摘要和校验信息；iOS 通过 TestFlight，Android 签名 APK 放私有 GitHub 分发仓库。
