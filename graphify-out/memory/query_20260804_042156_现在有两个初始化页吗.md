# Q: 现在有两个初始化页吗

## Answer

Expanded from original query via graph vocab: [startup, initialization, bootstrap, meettrace, model, download, preparation, ready, home]. 结论：应用冷启动不是两个独立初始化页面，而是一条启动门禁中的两个连续展示状态。MeetTraceBootstrap 先在依赖未就绪时显示 MeetTraceStartupView 的“正在打开本地工作区”，依赖完成后进入 MeetTraceRuntimeInitializationTransition；checking 状态继续复用同一基础内容，下载、校验、激活等阶段切换为“准备离线转录”。RecordingBootstrapView 是点击开始会议后的录音会话准备页，不属于应用冷启动初始化页。
