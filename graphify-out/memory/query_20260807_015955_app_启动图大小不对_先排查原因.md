# Q: app 启动图大小不对，先排查原因

## Answer

Expanded from original query via graph vocab: [startup, launch, screen, image, asset, assets, icon, logo, android, ios, native, flutter]. 根因是两套启动图管线使用了不同缩放语义：flutter_native_splash 2.4.8 将普通 image 视作 @4x，288px 源图输出 72px 画布，实际可见标志仅约 39x33 逻辑像素；Android 12+ 的 1152px 图按系统 288dp 图标槽呈现，实际约 153x127dp；Flutter 首帧品牌标志从 72dp 开始并收至 52dp。因此 Android 12+ 原生图约为 Flutter 首帧 2.1 倍，而旧 Android/iOS 反而偏小。Android 16 模拟器实测原生标志 402x333px，420dpi 下约 153x127dp。仓库没有跨平台光学尺寸合同或平台启动图回归测试。
