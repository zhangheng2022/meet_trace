# Q: 安卓为什么不奔溃

## Answer

Expanded from original query via vocab: [android, ios, memory, pressure, crash, native, finalization, proc, rss, monitor, risk, thermal]. Android 没崩不代表泄漏不存在。当前连接的小米 Mi 10 实测 MemTotal 7,794,712 kB、MemAvailable 约 3.0 GB、SwapTotal 6 GB，单次最终转录尚有较大余量。Android 还使用 AndroidProcAsrDeviceRiskMonitor 读取 /proc/meminfo：总内存至少 6 GiB 标记 supported、可用内存低于 512 MiB 标记 critical，ASR 后续窗口会被阻断；iOS 使用 PortableAsrDeviceRiskMonitor，memoryPressure 和 thermalState 始终 unknown，不会主动阻断。相同 sherpa_onnx 1.13.4 整段波形原生泄漏在 Android 同样存在，但 Android 真机的大 RAM、swap/zram 和不同的系统进程回收门槛使它暂未达到杀进程阈值。低内存 Android、长会议或重复分离仍可能崩溃。
