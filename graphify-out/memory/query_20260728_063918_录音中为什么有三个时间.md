# Q: 录音中为什么有三个时间

## Answer

Expanded from original query via vocab: [recording, session, elapsed, duration, time, timer, clock, waveform, transcription, backlog, timestamp, recorded]. 录音页只有一个真实录音时长 viewModel.duration。大号 00:00:00 是主计时；其下 AppTimeRuler 和 _TimeRulerLabels 又把同一时长绘制为 30 秒窗口。手机宽度小于 430 时显示起点、加 15 秒、加 30 秒三个刻度，且右侧可能是未来时间。它们不是三个计时器，而是装饰性时间尺；当前没有可拖动时间轴或波形数据，信息重复且容易误解，建议保留主计时并移除时间尺及刻度。
