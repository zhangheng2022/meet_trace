# Q: 列表增加删除功能，先给我方案

## Answer

推荐在每条会议账本行右侧增加48dp更多菜单，删除入口置于菜单中；点击后使用Forui二次确认，明确永久删除本地音频、转录、总结、证据索引和处理记录。录音中与后台处理中禁止删除。MeetingListViewModel注入并复用DeleteMeetingUseCase，维护单行删除状态；成功由仓库流移除记录，失败保留行并提示。平板删除当前选中项后选择相邻会议。补充ViewModel、Widget及事务删除测试。
