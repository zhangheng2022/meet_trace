# Q: 分析 iOS 端最终转录软件崩溃

## Answer

Runner-2026-08-06-100433.ips 证实本次不是 Jetsam/OOM，而是 DartWorker 上 sherpa_onnx 说话人分离回调链触发 SIGABRT。应用调用 processWithCallback；sherpa_onnx 1.13.4 使用 NativeCallable.isolateLocal，而 Dart SDK 明确规定该回调只能由创建它的 isolate mutator 线程调用，其他线程调用会 abort。崩溃栈包含 SherpaOnnxOfflineSpeakerDiarizationProcessWithCallbackNoArg +124。

## Outcome

- Signal: corrected
- Correction: 以 .ips 原始证据为准，撤销此前将本次事故归因于 Jetsam/OOM 的结论；内存泄漏仍是独立风险，但不是这份日志记录的直接终止原因。
