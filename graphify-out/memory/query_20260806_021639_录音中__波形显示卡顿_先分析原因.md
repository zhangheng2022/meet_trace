# Q: 录音中  波形显示卡顿，先分析原因

## Answer

Expanded from original query via graph vocab: [recording, waveform, amplitude, levels, repaint, painter, render, notify, state, chunk, sample, preview]. 主因是 ReliableRecordingService 默认按 250ms 批量等待并在 writeFrom+flush 后才将同批 PCM chunk 投递给 PcmAudioLevelMeter；meter 虽每 100ms 产生一个电平，但多个电平同步突发，Flutter 同一事件循环只绘制最终列表，波形每次跳 2~3 个槽。RecordingAudioWaveform 的 140ms 动画进一步形成约 140ms 动画+至少110ms静止的停走节奏。次因是同批 chunk 随后还在 UI isolate 同步进行 PCM 解码和 Silero VAD accept，可能拉长帧间隔。CustomPainter 仅48条线且有 RepaintBoundary，列表复制也仅48项，不是主因。回归由提交 ff8c59b 引入；测试工厂将 factCommitInterval 默认覆盖为 Duration.zero，未覆盖生产250ms节奏。
