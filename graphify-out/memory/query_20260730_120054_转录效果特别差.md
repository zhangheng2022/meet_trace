# Q: 转录效果特别差

## Answer

Expanded from original query via graph vocab: [whisper, audio, pcm, sample, language, vad, transcribe, transcription, segment, prompt, decoder, decode, threshold, token, translate, model]. 诊断结论：PCM16 录制与 /32768 Float32 解码正确，主要质量退化来自识别策略与未经评测的模型组合。StreamingWindowSegmenter 明确不是 VAD，却按 2 秒窗口把静音也送入 Whisper；WhisperRecognizerConfig 默认 language=auto，mt_whisper_transcribe 对每个短窗口独立自动判语种且 no_context=true，导致短语音/静音时语种漂移、上下文丢失和幻觉。标准模型还是 59.7MB Base Q5_1。Step_20 文档明确 Base/Small 同语料指标未完成，alpha_release_input.example.json 的质量/性能字段仍全为 null，因此替换仅验证可构建和可运行，没有通过关键事实召回率等发布门槛。建议阻断当前 Whisper Base/Small 作为正式默认；优先恢复 sherpa 中文双模型与 Silero VAD，Whisper 只保留实验或显式多语言选项。若坚持 Whisper-only，至少需会议级语言锁定、真正 VAD/静音门控、较长语义窗与 Small 模型同语料复测，但 Mi 10 性能证据显示其不适合作为默认实时模型。
