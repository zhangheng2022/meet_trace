# Q: 实时转录没有成功的根因是什么，如何修复

## Answer

根因不是 VAD 或模型加载失败，而是会中仍使用 Baseline Profile，Silero 只在长语音段结束后产出，并且 native 未设置 audio_ctx，导致短 PCM 也按完整 30 秒上下文推理。修复为预览三秒稳定子区间、Preview Greedy best-of 1、四线程，并按实际样本数设置 whisper_full_params.audio_ctx；最终转录仍使用独立事实 PCM、Baseline Profile 和双线程。Android x64 真实会议 PCM 已验证非空文本，三秒片段推理由约 11.6 秒降至约 5.8 秒。
