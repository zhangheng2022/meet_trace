# Q: 其他方案

## Answer

Expanded from original query via graph vocab: [asr, whisper, transcription, preview, engine, model, quality, streaming, recognizer, sherpa]. 当前最现实的其他方案是：短期保留 whisper.cpp 做最终转录，实时预览在低置信时降级为仅录音；若实时字幕是核心能力，使用 sherpa-onnx OnlineRecognizer 与真正流式的中文 Zipformer/Paraformer 做同设备同 PCM Spike。不要直接恢复仓库旧的 OfflineRecognizer Paraformer 适配器，因为它仍是窗口式离线识别。双引擎方案（Sherpa 实时预览 + Whisper 最终）体验潜力最高，但违反当前“会议模型锁定、会中和最终使用同一模型”边界，必须先更新 PRD。系统原生 ASR 跨设备一致性不足，云端流式 ASR违反当前禁止音频上传的产品边界。当前 Whisper 源码修正尚缺小米同 PCM 真机 A/B，不能据此断言修复后的版本仍不合格。
